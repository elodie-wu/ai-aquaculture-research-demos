# 🐟 AI Aquaculture Research Demos

A collection of applied AI experiments exploring how machine learning, optimisation, anomaly detection, and computer vision can support aquaculture, fisheries, and protected species monitoring.

## 📚 Projects

| Project                                                                                       | Topic                                          | Methods                                           | Status       |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------- | ------------ |
| [🌊 Environmental Risk and Anomaly Detection](./01-environmental-risk-and-anomaly-detection/) | Water-quality assessment and anomaly detection | Random Forest, GA, NSGA-II, Isolation Forest, LOF | ✅ Completed |
| [🐠 Fish Disease Detection](./02-fish-disease-detection/)                                     | Fish health image classification               | CNN, Transfer Learning                            | ✅ Completed |
| [🐢 Sea Turtle Detection in Video](./03-sea-turtle-video-detection/)                          | Protected species detection in video           | Object Detection, YOLO                            | ✅ Completed |

## 🧰 Technologies

Python, Pandas, NumPy, Scikit-learn, DEAP, PyTorch, Ultralytics YOLO, OpenCV, Matplotlib

## 🎯 Research Focus

These projects explore different AI approaches for:

- environmental monitoring
- fish health analysis
- feature optimisation
- anomaly detection
- computer vision
- protected species monitoring
